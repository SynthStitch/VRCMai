# VRCMai

maimai-style rhythm game world for VRChat (UdonSharp). Judging rules are ported from
[MajdataPlay](https://github.com/LingFeng-bbben/MajdataPlay), so this project is GPL-3.0.

- Unity 2022.3.22f1, VRChat Worlds SDK 3.10.x (open with VCC, it restores the packages)
- Charts (`Assets/Maimai/Charts`) and the world map are not included; add your own simai charts and run `Maimai/Rebuild Song List`
- Fonts: Space Mono, Doto, Noto Sans SC (SIL OFL, licenses in `Assets/Maimai/Fonts`)
